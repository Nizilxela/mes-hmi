# MES HMI Utility

Веб-утилита для интеграции с码垛机 (паллетизатором) по протоколу **MES TCP/IP** (текстовые команды, порт `10000`).

Заменяет ручной ввод команд через telnet: даёт удобный веб-интерфейс для чтения статуса, управления рецептами, счётчиками и запуском/остановкой станка.

## Возможности

- **Мониторинг в реальном времени**: статус робота, левый/правый счётчик, суммы, флаги завершения паллетирования.
- **Управление рецептами**: запрос списков `SENDL`/`SENDR`, переключение левого и правого рецепта одной командой.
- **Команды управления**: `SETSTART`, `SETSTOP`, `SETPL`, `SETPR`, `SETCL`, `SETCR`, `SETLNUM`, `SETRNUM`.
- **Произвольная команда**: поле для отладки — любую строку можно отправить напрямую и увидеть ответ.
- **Журнал**: все запросы и ответы видны в интерфейсе.
- **Экспорт конфигурации**: можно сохранить текущие настройки в одиночный HTML-файл.
- **Docker-образ**: запуск одной командой на любой ОС с Docker, без установки Python.
